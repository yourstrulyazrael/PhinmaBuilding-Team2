# 48 — A more modern look: the foundation

**What to build:** the whole app looks more modern, with the same colours
(forest green, navy, white; and their dark-mode versions).

**Blocked by:** None

**Status:** done (check on the live URL)

- [x] A modern interface font (Geist), served from our own site
- [x] Rounder corners; cards with a soft, layered shadow instead of a
      hard grey edge; a faint green glow at the top of every page
- [x] Buttons: a soft shadow, a slight press when tapped, a soft green
      focus glow; even spacing between icon and text everywhere
- [x] Inputs, text boxes and dropdowns: white, rounder, a soft green
      glow and border when focused
- [x] One page header on every page: back link where useful, a small
      green label with an icon, the title, a description, and the
      page's main buttons on the right
- [x] Workspace tabs are a segmented switch
- [x] Colours unchanged in light and dark mode; printed slips and
      reports unaffected
- [ ] Works on the live URL, at phone width, in light and dark mode
