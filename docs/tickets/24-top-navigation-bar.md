# 24 — Top navigation bar with icon-only buttons

**What to build:** the sidebar is replaced by one navigation bar across
the top, on every screen size. Its buttons show only their icons; each
name slides out when pointed at. UI polish requested by the team; no
change to data or security.

**Blocked by:** 16

**Status:** done

- [ ] One sticky top bar on phone, tablet and laptop; no sidebar
- [ ] Overview, Add a repair, Workspace and My details show as icons;
      the current page is highlighted
- [ ] Pointing at a button (or Tabbing to it) slides its name out;
      screen readers always hear the name
- [ ] The theme control is one button cycling Light → Dark → System
- [ ] Who is signed in (initials) shows their name and number on hover
- [ ] Sign out is in the bar
- [ ] Fits a 360px-wide phone without scrolling sideways
- [ ] The top bar never prints on a claim slip
- [ ] Works on the live URL
