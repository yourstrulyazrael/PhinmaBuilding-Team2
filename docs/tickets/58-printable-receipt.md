# 58 — Printable payment receipt at pickup

**What to build:** once a repair is paid for, the shop can print (or
save as PDF) a receipt for the customer. This moves receipts into scope.

**Blocked by:** 57

**Status:** done (check on the live URL)

- [x] A **Receipt** button on the repair page once a payment is recorded
- [x] The receipt: shop name, contact and address; "Payment receipt", a
      short number and the payment date; customer name (never their
      number), device, repair and technician
- [x] The quote (initial, or revised with the initial shown), each part
      with its price, and the total, in the shop's currency
- [x] Amount paid, how (with the reference), any balance, and the
      warranty end date
- [x] "Thank you!", the shop's slip note, and "Acknowledgement of payment.
      This is not an official receipt."
- [x] Prints cleanly on one page (or "Save as PDF" on a phone)
- [ ] Works on the live URL
