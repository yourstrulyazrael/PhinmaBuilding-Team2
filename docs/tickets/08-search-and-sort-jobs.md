# 08 — Search and sort the Jobs list

**What to build:** the technician types into a search box on the Jobs
list to find a repair by device, problem, customer name or customer
phone, and picks how the list is sorted. Added after the MVP, from
`docs/LATER.md`.

**Blocked by:** 03

**Status:** done

- [x] A search box on the Jobs list matches device, problem, customer
      name and customer phone, ignoring upper/lower case
- [x] A sort menu offers: promised date (soonest first, the default),
      newest added, oldest added, customer name A–Z
- [x] Search and sort apply to the open jobs and the "Done" section, and
      stay in place when switching between the All / Ready / Waiting on
      parts tabs
- [x] When nothing matches, the list says so and offers a way to clear
      the search
- [x] The search is in the page address, so the browser's Back button
      and refresh keep it
- [x] The summary counts at the top still count every job, not just the
      matches
- [x] Works at phone width
- [x] Works on the live URL
